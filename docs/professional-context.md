6. Optionally generate translated or bilingual subtitle tracks.
7. Generate structured meeting minutes, including an executive overview, highlights, speaker-aware discussion records, topics, decisions, and action items.

### Shifaa - Privacy-First Hospital Clinical Decision Support

**Dates:** October 2025 - July 2026  
**Context:** Graduation project, Ain Shams University.  
**Repository:** <https://github.com/omarelnokrashy/Shifaa-AI-Based-Patient-Monitoring-System/tree/Windows-Deployment>

- Privacy-first, on-premises patient-monitoring platform combining a grounded medical assistant with cardiac-arrhythmia, fall-detection, and seizure-detection systems.
- Personal contribution: engineered the hybrid real-time seizure-detection pipeline using Vision Transformers, Graph Neural Networks, OpenPose, ONNX Runtime, C++, and Python.
- Reported seizure-pipeline results: 96.69% AUROC, 90.18% F1-score, and 37+ FPS, with pre-clinical seizure alerts.

**Boundary:** Describe Shifaa as an academic project with reported metrics. Do not claim clinical validation, hospital readiness, or medical-device approval.

**Public repository architecture**

- **Backend:** FastAPI/Uvicorn gateway with REST, WebSocket, and server-sent-event interfaces; JWT and bcrypt authentication; endpoint-level RBAC; SQLAlchemy over SQLite or PostgreSQL.
- **Frontend:** React 18, Vite, Tailwind CSS, Zustand, React Router, Axios, and Recharts; role-aware doctor, nurse, and admin views.
- **Inference services:** independent arrhythmia, fall-detection, and seizure-detection services, each with dedicated code and documentation.
- **Seizure pipeline:** C++/ONNX native runtime coordinated with a Python ViViT worker through Win32 named-pipe IPC; the public repository reports approximately 37.2 FPS steady-state throughput.
- **Fall pipeline:** public repository describes YOLO, role classification, pose analysis, and CTR-GCN stages; repository-reported metrics are 91.59% accuracy, 94.87% F1, and 98.83% recall.
- **Arrhythmia pipeline:** two-stage CNN-BiLSTM-Attention cascade with handcrafted QRS and heart-rate features; repository documents strict patient-level split isolation.
- **Grounded assistant:** local-first LLM configuration, patient-record intent handling, and local deployment options using Ollama or an OpenAI-compatible provider.
- **Operations:** alert lifecycle persists, broadcasts, acknowledges, and archives alerts to preserve an audit trail; deployment assets include Docker, systemd, and orchestration material.

**Individual-contribution boundary**

The public repository is a team graduation project. Omar's documented individual contribution is the hybrid real-time seizure-detection pipeline. Attribute other system components to the Shifaa team unless Omar's ownership is independently verified.
